# Day-5: сравнение моделей

Запустите отдельный режим:

```powershell
$env:PROXYAPI_API_KEY = "ваш API-ключ"
dotnet run -- --benchmark day5
```

Этот запуск использует те же восемь задач, что и Day-3, и отправляет каждую задачу напрямую каждой из трёх моделей. Запросы независимые: модель получает только текст текущей задачи, без истории других запросов. Всего будет 24 запроса.

## Зафиксированные модели

Все три модели вызываются через один ProxyAPI endpoint, чтобы не смешивать различия API-провайдеров:

| Уровень | ID модели | Вход, ₽ / 1 млн токенов | Выход, ₽ / 1 млн токенов |
|---|---|---:|---:|
| Бюджетная | `deepseek/deepseek-v4.1-flash` | 26,07 | 100,25 |
| Средняя | `openai/gpt-6-sol` | 420 | 2 100 |
| Флагманская | `openai/gpt-6-astra` | 1 580 | 7 900 |

Цены взяты из [каталога моделей ProxyAPI](https://proxyapi.ru/models/browse) и зафиксированы в коде как снимок от 2026-11-08. Каталог может менять тарифы, поэтому перед повторным запуском сравните снимок с актуальными ставками.

Расчётная стоимость рассчитывается отдельно по `prompt_tokens` и `completion_tokens`, которые вернул API:

```text
(prompt_tokens × цена_ввода + completion_tokens × цена_вывода) / 1 000 000
```

Это оценка по стандартному прайс-листу, а не выписка фактического списания; скидки за кэшированные токены не учитываются. Если API не вернул usage-токены, стоимость будет указана как `н/д`, а не как ноль. Скорость выводится как суммарное время и среднее время на одну задачу. Время включает полный API round trip. Все модели получают одинаковую формулировку задачи без дополнительных промптов; уровень рассуждения не переопределяется.

## Файлы результата

По умолчанию будут созданы:

- `benchmark-results-Day-5.csv` — таблица для Excel или Sheets;
- `benchmark-results-Day-5.md` — таблица и вывод о точности, скорости и задачах, где бюджетной модели хватило;
- `benchmark-results-Day-5.json` — ответы и метрики по каждой задаче и модели.

Параметр `--output results/day5.csv` позволяет изменить базовый путь; соседние Markdown и JSON сохранят тот же basename. `dotnet run -- --benchmark day5 --help` показывает все параметры.
