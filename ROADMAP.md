# Дальнейшее развитие

Основа для следующих учебных заданий: отдельные модули `IBenchmark`, агенты `IAgent`, провайдеры `IAIProvider`, общие операции `IWorkspaceClient`. Новые задания не требуют добавлять бизнес-логику в страницы и консольный цикл.

## Отложено явно: миграции базы

- Перейти с пересоздания учебной SQLite на EF Core migrations.
- Продумать baseline существующей схемы и переход без удаления истории.
- Проверить обновление копии старой БД, резервное копирование и восстановление.
- До выполнения этого пункта изменение отпечатка схемы удаляет старые диалоги; файлы прогонов сохраняются.

## По мере появления соответствующих заданий

- Реальный streaming провайдеров, токенов ответа и событий инструментов. Сейчас интерфейс показывает этапы бенчмарка и готовый ответ чата; наличие метода StreamMessageAsync не означает реализованную поддержку.
- Новые способы памяти за отдельным контрактом стратегий; ретроспективное построение facts по архиву и токеновый бюджет контекста.
- Выполнение локальных моделей через собственные протоколы, управление загрузкой и профили конкретных моделей. Текущие Ollama/LM Studio профили используют OpenAI-compatible HTTP.
- Долговечная очередь с возобновлением по шагам, политикой идемпотентности и учётом неоднозначного исхода платного запроса. Сейчас после перезапуска прогоны помечаются Interrupted без автоматических повторов.
- Повторные измерения, распределения задержек, интервалы качества, управление бюджетом и ограничением частоты запросов. Начальный последовательный режим сохраняет условия существующих экспериментов.
- Работа с очень длинными архивами: отдельные агрегаты usage и токенов, загрузка активного контекста без чтения всего журнала. Пагинация истории интерфейсов уже есть.
- Раздельные учётные записи, права на диалоги и задания, ограничения ресурсов пользователей.
- PostgreSQL и согласование нескольких серверных процессов, когда этого потребует нагрузка. Один VPS и несколько клиентов сами по себе не требуют замены SQLite.
- Отдельное WPF-приложение как клиент того же HTTP API при появлении задач интеграции с Windows.
