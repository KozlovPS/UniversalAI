# Day-4: влияние temperature

Запуск:

```powershell
$env:PROXYAPI_API_KEY = "ваш ключ ProxyAPI"
dotnet run -- --benchmark day4
```

Эксперимент фиксирует модель `openai/gpt-4o-mini` через ProxyAPI, чтобы сравнивать только температуру. Модель поддерживает параметр `temperature`. Для каждой комбинации температуры (`0`, `0.7`, `1.2`) и типа задачи отправляется пять отдельных запросов, всего 30.

## Типы задач

1. **Один правильный ответ:** вычислить `17 × 19`; правильный ответ — `323`. Формат: одна строка `ANSWER: 323`.
2. **Генерация:** придумать ровно пять названий на русском для приложения планирования личного бюджета; формат — пять пронумерованных строк.

Каждый запрос получает только условие своей задачи, без предыдущих ответов. В JSON сохраняются все повторы.

## Метрики и вывод

- У задачи с одним ответом отдельно считается точность и соответствие формату.
- Для генерации считаются сбои формата, число различных полных ответов и число уникальных названий во всех пяти прогонах.
- Для каждой группы выводятся токены и время API-вызовов.
- Markdown показывает пример ответа на каждом значении temperature и формирует вывод: повторился ли ответ при `temperature=0`, какое значение оказалось стабильнее для точной задачи и какое дало больше валидных вариантов для генерации.

Разнообразие считается по точным текстам после нормализации пробелов; для вариантов названий — по уникальным строкам без учёта регистра. Автоматическая проверка тематики названий не выполняется: она проверяет заданный формат и показывает ответы для ручной оценки.

По умолчанию создаются `benchmark-results-Day-4.csv`, `benchmark-results-Day-4.md` и `benchmark-results-Day-4.json`. Путь можно изменить параметром `--output`; рядом будут созданы Markdown и JSON с тем же basename. Все параметры: `dotnet run -- --benchmark day4 --help`.
