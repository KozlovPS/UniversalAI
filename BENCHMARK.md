# Эксперимент с промптингом и reasoning

Запустите эксперимент отдельным режимом приложения:

```powershell
$env:PROXYAPI_API_KEY = "ваш API-ключ"
dotnet run -- --benchmark
```

По умолчанию используются ProxyAPI, модель из `OpenAICompatibleOptions` и восемь задач с заранее заданными ответами. Для другой модели или OpenAI-совместимого API:

```powershell
dotnet run -- --benchmark --provider ProxyAPI --model deepseek/deepseek-v4.1-flash
```

Доступные параметры можно посмотреть командой `dotnet run -- --benchmark --help`. Параметр `--base-url` задаёт адрес совместимого API, `--api-key-env` — имя переменной окружения с ключом. Для моделей, где `high` является верхним уровнем рассуждения, он выбирается автоматически. Для DeepSeek V4.1 Flash и GPT-6 Luna автоматически используется `max`; уровень можно переопределить через `--high-effort`.

Каждая из четырёх стратегий запускается на всех восьми задачах с `low` и максимальным уровнем reasoning. Для стратегии генерации промпта учитываются оба API-вызова: составление инструкции и решение задачи. Время — сумма длительности последовательных вызовов. Токены суммируются по `usage.total_tokens` API; если поле отсутствует, берутся `prompt_tokens + completion_tokens`.

Для группы экспертов модель должна выдать ответы аналитика, инженера и критика. Задача засчитывается, если большинство распознанных ответов верно. Для остальных стратегий проверяется помеченный `ANSWER`/`ОТВЕТ` ответ; у прямого ответа, где формат не задаётся, берётся последнее числовое значение. Подробные ответы и ошибки сохраняются для ручной проверки.

После запуска создаются три файла рядом с приложением (или по пути из `--output`):

- `benchmark-results.csv` — агрегированная таблица для Excel или Sheets;
- `benchmark-results.md` — таблица и автоматическая сводка о приросте точности;
- `benchmark-results.json` — ответы модели, извлечённые ответы, токены и ошибки для каждой задачи.

Пример с другим именем выходных файлов:

```powershell
dotnet run -- --benchmark --output results/reasoning.csv
```

Режим отправляет 80 API-запросов: по одному для каждого сочетания задачи, стратегии и уровня reasoning, плюс отдельный запрос генерации промпта для каждой задачи на каждом уровне reasoning. Реальный запуск выполняется пользователем явно командой выше.
